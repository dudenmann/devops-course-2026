# Git в IDE vs Терминал

## Удобно в VS Code
1. Визуализация diff — сразу видно добавленные и удалённые строки.
2. Встроенный редактор конфликтов — кнопки Accept Current/Incoming.
3. GitLens показывает, кто и когда менял каждую строку.

## Удобнее в терминале
- Rebase, squash, cherry-pick, reset — в UI скрыты или неудобны.
